# AI Usage Documentation

## Project
Corporate Event Management API

## AI Tool Used
- ChatGPT (GPT-6)

## Purpose of AI Assistance

ChatGPT was used as a learning and development assistant throughout the project.

Assistance included:

1. Understanding FastAPI project architecture and REST API concepts.
2. Learning how to configure PostgreSQL and connect it using SQLAlchemy.
3. Understanding database models and Pydantic schemas.
4. Implementing and understanding event CRUD operations.
5. Developing employee registration functionality and business rules.
6. Understanding HTTP status codes and request validation.
7. Creating automated tests using Pytest.
8. Troubleshooting development errors and understanding terminal commands.
9. Preparing project documentation and GitHub instructions.

## Example Prompts

- "How can I learn FastAPI?"
- "I have a project I want to build from scratch. Guide me step by step."
- "Explain where to write the code and what each part does."
- "Help me test event creation and employee registration."
- "Explain how to test duplicate registrations and event capacity."
